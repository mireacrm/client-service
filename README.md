# Сервис клиентов

Карточки клиентов, история визитов и программа лояльности. Отвечает
по gRPC записи и биллингу, сам ходит в ядро за филиалом.

## Архитектура

Сервис владеет контекстом «Клиенты»: карточками клиентов, их контактами и
балансом баллов лояльности (`client_db`, миграции через Alembic).

Как gRPC-сервер отвечает на запросы:

| Кто вызывает          | Метод                  | Зачем                                   |
| --------------------- | ---------------------- | ---------------------------------------- |
| billing-service        | `AddLoyaltyPoints`     | Начислить баллы после оплаты счёта (идемпотентно по `invoice_id`) |
| notification-service    | `GetClientContacts`   | Получить контакты клиента для рассылки  |

Как gRPC-клиент сам ходит за данными:

| Куда ходит   | Метод                    | Зачем                              |
| ------------ | ------------------------ | ----------------------------------- |
| core-service | `GetBranch`              | Проверить филиал при регистрации клиента |
| booking-service | `ListClientAppointments` | Отдать историю записей клиента     |

Контракты (proto-сообщения и стабы) приезжают из `mirea-contracts`,
инфраструктурный каркас (метрики, трассировка, ошибки, доступ к БД) — из
`mireacrm-common`. Обе зависимости версионируются в `pyproject.toml`.

## Тесты

`tests/unit` — модульные тесты бизнес-логики без внешних зависимостей.
`tests/integration` — поднимают Postgres и проверяют миграции и реальные
запросы к БД. Идемпотентность `AddLoyaltyPoints` (баллы не начисляются
дважды по одному `invoice_id`) проверяется отдельным тестом в этом наборе.

## Зависимости

| Пакет | Роль |
|---|---|
| [`mirea-contracts`](https://github.com/mireacrm/contracts-py) | сообщения и стабы gRPC |
| [`mireacrm-common`](https://github.com/mireacrm/py-common) | настройки, метрики, трасса, ошибки, база, события, gRPC |

Оба приезжают из своих репозиториев по версии из `pyproject.toml`.
Версию контрактов называет сервис, а не обвяз: два прямых URL одного
пакета pip считает конфликтом.

## Локально

```
pip install -e ".[dev]"
python -m pytest tests/unit -q
python -m pytest tests/integration -q   # нужен Postgres
docker build -t client-service .
```

Систему целиком поднимает [`mireacrm/deploy`](https://github.com/mireacrm/deploy).
